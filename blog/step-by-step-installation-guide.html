Step-by-Step: How to Install and Set Up AffiliCart on Your WordPress Site

Tutorials
⏱️ 5 min read

Introduction

New to Amazon affiliate plugins? AffiliCart is deliberately simple—no coding required. This guide walks you through installation to your first live cart in under 15 minutes.

Prerequisites

  • WordPress 5.0 or higher
  • Active Amazon Associates account
  • Recommended: custom domain (not WordPress.com free plan)

Option A: Install Directly from WordPress (Recommended)

  1. Log into your WordPress dashboard.
  2. Go to Plugins → Add New.
  3. Search "AffiliCart".
  4. Click Install Now → Activate.

You'll now see "AffiliCart" in your admin menu.

Option B: Manual Upload

Download the latest version from affilicartpro.com or the WordPress directory, then upload via Plugins → Add New → Upload Plugin.

Step 2: Add Your Amazon Associates Tag

  1. Go to AffiliCart → Settings.
  2. Paste your tracking ID (e.g., yoursite-20).
  3. Save.
Pro Tip: Test it immediately—create a product, add to cart, and verify your tag appears in the Amazon checkout URL.

Step 3: Add Your First Product

  1. Click AffiliCart → Add Product.
  2. Fill in: Product Name, Description, ASIN (copy with the free Chrome extension), Image, Category.
  3. Save.

Step 4: Display Products on Any Page

Use shortcodes anywhere in your posts or pages:

  • Full grid: [affilicart_grid]
  • Single product: [affilicart_grid id="123"]
  • Minimal button: [affilicart_button id="123"]
  • Hover link: [affilicart_link id="123" text="Check price"]

Hide elements easily: show-description="no", etc.

Troubleshooting Common First-Time Issues

Shortcode shows as plain text? Clear cache or switch to Block Editor.

Tag not saving? Double-check format and admin permissions.

Mobile layout off? Test with a default theme—AffiliCart is fully responsive.

You're Live!

Your readers can now browse products, add multiple items, and checkout on Amazon with your affiliate tag attached automatically.
