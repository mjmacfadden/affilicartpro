## Site Purpose
AffiliCart is a WordPress plugin that gives Amazon Associates creators a real, persistent shopping cart experience directly on their sites.

## Core Product Description
AffiliCart allows visitors to:
- Add multiple Amazon products to a single cart
- Browse and shop across an entire site without losing their selections
- Select exact product variants (sizes, colors, etc.) on-site (Pro feature)
- Checkout once on Amazon with the full pre-loaded cart and the site owner's affiliate tag attached

## Key Features
- AffiliCart Light: Completely free version with persistent cart, auto-tagging, and shortcodes
- Pro version: Custom accent colors, cart icon placement, and powerful on-site product variants (XS–XXXL, shoe sizes, pants measurements, custom options)
- Auto-tagging for all Amazon links (including shortened a.co links)
- Easy shortcodes for product grids, add-to-cart buttons, and hover previews
- Fully responsive and lightweight

## Origin Story
AffiliCart was originally built for entrepreneurship students at trypursueit.com to help them recommend hobby products more effectively. It was later released publicly as a tool for all Amazon Associates creators.

## Differentiation
Unlike traditional Amazon affiliate plugins that only display product boxes or single links, AffiliCart provides a true e-commerce-style shopping cart experience. This significantly reduces bounce rates and increases average order value by letting readers build complete outfits, project kits, or recipe ingredient lists on the publisher's site.
